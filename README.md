# 稀疏表面张量的自适应分位滤波

分位滤波资料来自两种合成表面。少量量化级落在同一校准台阶。 数据为本地合成。

- `data/capture.json` 保存采集原始内容。records 是交换记录，tensors 字段分开描述名称、类型、形状和值。整数索引从零开始，未指定闭合的区间均为左闭右开。
- `data/capacity.json` 保存制造端的容量、规模或分片条件。大尺寸是接口需考虑的使用规模。工作区计入新分配的解包、转换、归约、版本暂存及交接缓冲。调用方已有只读输入和已消费的输出不计入工作区，额外物化副本计入。

## 交换约定

物理轴间距按行、列给出，窗口用相同物理半径分别比两轴绝对间距。静态材料图由产品工艺给出，即使未采到量化码也可判断潜在同材候选。读头定标表索引是整数码，值为可精确比较的整数微单位。已确认永久无读数与仍可能补交的样本分别由状态 −1 与 0 指明，状态 1 是实际读数。未齐资料允许任意合法码，所以只有对所有可能补交均保持承诺输出时才可交付。
超差判定采用目标物理值减分位物理值的绝对差达到 `threshold`。量化码是否有符号与物理值不同，每个读取点沿自己的拥有者和定标表换算。各读头按窗口与材料返回按量化码计数的资料，以及被查询码值中指定次序的样本 ID。相同物理定标值可由多个不同码值形成。ID 按全局行列字典序；计数不包含未知或确认无读数的样本，状态图仍包含它们。

## 读取资料

使用 Python 3.11。首次创建本地环境时安装锁定依赖。只读查看显示原始字段和张量尺寸。

```sh
python -m pip install -r requirements.txt
python caseio.py data/capture.json
python -m unittest discover -s tests -v
```

现有检查核对采集格式和所附数据的结构。
