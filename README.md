# 稀疏表面张量的自适应分位滤波

分位滤波资料来自两种合成表面。少量量化级落在同一校准台阶。 数据为本地合成。

- `data/capture.json` 保存采集原始内容。records 是交换记录，tensors 字段分开描述名称、类型、形状和值。整数索引从零开始，未指定闭合的区间均为左闭右开。
- `data/capacity.json` 保存制造端的容量、规模或分片条件。大尺寸是接口需考虑的使用规模。工作区计入新分配的解包、转换、归约、版本暂存及交接缓冲。调用方已有只读输入和已消费的输出不计入工作区，额外物化副本计入。

## 交换约定

物理轴间距按行、列给出，窗口用相同物理半径分别比两轴绝对间距。静态材料图由产品工艺给出，即使未采到量化码也可判断潜在同材候选。读头定标表索引是整数码，值为可精确比较的整数微单位。已确认永久无读数与仍可能补交的样本分别由状态 −1 与 0 指明，状态 1 是实际读数。未齐资料允许任意合法码，所以只有对所有可能补交均保持承诺输出时才可交付。
超差判定采用目标物理值减分位物理值的绝对差达到 `threshold`。量化码是否有符号与物理值不同，每个读取点沿自己的拥有者和定标表换算。各读头按窗口与材料返回按量化码计数的资料，以及被查询码值中指定次序的样本 ID。相同物理定标值可由多个不同码值形成。ID 按全局行列字典序；计数不包含未知或确认无读数的样本，状态图仍包含它们。
`frames` 标识读头资料、可用状态图及定标版。同一帧的读头响应应对应请求位置、实际查阅的窗口和材料、帧的格网及定标版。`query_replay` 记录同一查询先后收到的右读头定标版，窗口与材料由该位置的查询决定。换版与同版重发的记录以请求和响应各自声明的版本判断。

## 读取资料

## 自适应分位滤波算子（`roughquant`）

`roughquant` 是可复用的分块自适应分位滤波算子，提供两条等价路径：

- 汇合端 `AdaptiveQuantileFilter`（`aggregator.py`）：只通过读头受控应答取数，
  读头的原始量化码窗口永不离开读头；
- 本地直算 `evaluate_local`（`pipeline.py`）：在持有完整张量时直接走同一套
  核心原语（`core.py`），两条路径的逐字段结果必须一致（测试强制核对）。

模块划分：

| 模块 | 职责 |
| --- | --- |
| `geometry.py` | 采集地图、物理轴间距、闭合轴对齐矩形窗口、读头所有者、材料缝夹断 |
| `core.py` | 半径选择、秩/分位定义、平台见证、待判定可证明规则（与取数方式无关） |
| `heads.py` | 读头私有码值存储与两类受控应答（码值频次、指定次序样本身份） |
| `aggregator.py` | 分块算子、超预算递归拆分、边带增量累加、k 路归并见证、工作区预算 |
| `handoff.py` | 交接包与跨帧变化归因（半径 / 秩 / 定标三类） |
| `pipeline.py` | 从采集记录装配流水线、本地直算 |
| `detect.py` | 检测路径命令行，产出校正后分位、见证与超差交接状态 |

### 关键语义

- **窗口**：以已公布物理半径序列逐个尝试，按行/列各自的实际格点间距把物理
  半径换算为闭合矩形（内部用半开区间表达），只收同一材料类属的邻居，材料缝
  天然不跨入；选中第一个有效样本数达到 `minimum` 的半径。
- **样本与秩**：读头只沿自己的拥有者和定标表把码值换算为物理微单位；已知零值
  正常参与，未读（状态 0）与确认无读数（状态 −1）没有秩次。秩按校正物理值
  升序、同值按全局行列字典序的稳定 ID；分位取第 `ceil(q·n)` 项，`q` 为有理数。
- **平台见证**：同一物理值可由多个码值、两个读头共同形成。算子先由码值频次
  求分位物理值与秩，再对所有并列样本做 k 路归并，仅用“指定次序取身份”应答
  找回正确见证；用分位值代替见证会在换表后指向错误测量点，因此见证单独交付。
- **待判定的分量级证明**：半径、分位值、见证、超差四个分量各自标注确定性。
  - 半径确定 ⇔ 每个更小半径在“全部未读样本补交”后的潜力仍严格小于门槛；
  - 分位值确定 ⇔ 半径确定且未读样本同时取各读头定标表极小/极大两种极端补交
    的分位值相同；
  - 见证确定 ⇔ 半径确定且秩区间引理对任意合法补交都保持同一样本；
  - 超差确定 ⇔ 目标读数存在且分位值确定（区间两端同侧超差/合格时亦可发布）。
  只有证明后续可达资料不影响某分量时才发布该分量，无需全幅停等；资料可能
  改变邻域选择或秩见证的位置显式标 `pending`，永久无候选时标 `blocked`。
- **定标版本**：定标切换只作用于归它管辖的读头值。读头应答绑定请求帧的格网与
  定标版，旧版应答或答复未齐时，受影响位置整体按待判定交付，不静默采用旧基准。
- **隐私与预算**：读头只应答码值频次和指定次序身份，不交出完整窗口码值。频次
  条目超 `max_response_entries` 时汇合端递归拆分矩形后合并；半径窗口嵌套，大
  窗口只增量询问四条边带。工作区只计频次表、未读清单与单位置身份缓存，位置
  结束即释放，峰值不随邻域像素数线性增长，受 `peak_scratch_bytes` 约束。

### 运行

```sh
python -m roughquant.detect data/capture.json data/capacity.json out
```

交接包写到 `out/handoff.json`：`frames` 给出每帧逐位置的所选半径、矩形、有效/
未读数量、分位秩、分位物理值、见证身份与读头、目标读数、偏差、超差结论及四个
分量的确定性标记；`changes` 给出同一位置跨帧的单一归因（`radius` / `rank` /
`calibration` / `none`）；`replays` 给出 `query_replay` 中旧版/新版应答下的
待判定与可发布对照。

测试：

```sh
python -m unittest discover -s tests -v
```
